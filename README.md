# Make the AI Judge Laugh: Office Jokes

A make.fun entry for the bounty "Make the AI Judge Laugh: Office Jokes". The program writes one single-line joke about office life — at most 199 characters — to `/output/entry.txt`. The joke takes the shared office fridge as its angle: a "DO NOT TOUCH" label cannot protect a lunch, but labelling it "meeting notes" keeps it untouched for six months, because nobody in the office ever touches meeting notes.

Run it with `python3 main.py`; it writes the joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that variable is set, for local runs).
